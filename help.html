安装教程

  1. 下载启动器

    前往 下载页面，点击下载按钮获取最新版本的启动器压缩包。

  2. 解压文件

    将下载的 .zip 压缩包解压到任意目录（建议不要放在 C 盘系统目录下）。

  3. 运行启动器

    双击 PCL CE.exe 运行启动器。首次运行可能需要稍等片刻初始化。

  4. 注册/登录

    如果没有账号，点击启动器内的注册按钮，填写用户名、密码、邮箱并输入验证码完成注册。如有卡密可在注册时填写。

  5. 开始游戏

    登录后选择游戏版本，点击下载，下载完成后即可启动游戏。

账号登录

启动器支持两种账号系统：

  • liuying 账号：在官网或启动器中注册的账号，使用用户名和密码登录。需要有效的卡密才能激活使用。
  • 微软正版账号：使用你的 Minecraft 正版账号登录，支持浏览器自动授权。

如果忘记密码，可以在 账号页面 点击"忘记密码"通过邮箱重置。

微软正版登录

微软正版账号登录流程：

  1. 点击微软登录

    在启动器登录界面选择"微软账号登录"。

  2. 浏览器自动打开

    系统会自动打开浏览器，跳转到微软登录页面。

  3. 登录微软账号

    在浏览器中输入你的微软账号和密码，完成登录。

  4. 授权确认

    浏览器会显示授权确认页面，点击"是"授权。

  5. 自动完成

    浏览器页面显示登录成功后，启动器会自动接收回调，弹窗自动关闭，登录完成。

提示： 如果浏览器没有自动打开，请检查弹窗中显示的地址，手动复制到浏览器中打开。

下载游戏

登录后可以在主界面选择 Minecraft 版本：

  • 原版：Minecraft 官方版本，直接选择版本号下载。
  • Forge：安装 Forge 模组加载器后可运行模组。
  • Fabric：安装 Fabric 模组加载器。
  • OptiFine：光影和优化模组。

选择版本和加载器后，点击"开始下载"即可自动下载所需文件。

常见问题

请检查网络连接是否正常。如果使用代理，请确保代理设置正确。服务器可能偶尔维护，请稍后再试。

可以在启动器设置中切换下载源。如果在国内，建议使用 BMCLAPI 源以获得更快的下载速度。

请确保使用主流浏览器（Chrome、Edge）。如果页面空白，尝试清除浏览器缓存或使用无痕模式重新登录。

卡密在注册账号时填入"卡密"字段即可激活。已注册的账号可以在启动器内点击"激活卡密"延长使用期限。

Minecraft 需要 Java 运行环境。启动器通常会自动下载 Java，如果没有自动下载，请手动安装 Java 17 或以上版本。

查看启动器日志（设置 → 日志），常见的崩溃原因包括：内存不足、模组冲突、Java 版本不匹配。可以尝试减少内存分配或检查模组兼容性。

登录后在 个人中心 点击"上传头像"，选择 PNG 格式的图片（300KB 以内）上传即可。
